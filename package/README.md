# ARIES Weapon Detection Demo Package

This package is the deployable source bundle for the MLA100 weapon detection demo.

## Package Contents

The archive generated by `package/package.sh` contains:

- `src/demo/` source code
- `rc/` configuration files, layout images, and sample videos
- `mxq/` model files
- `Makefile` for package-local builds
- bundled `qbruntime` and `yaml-cpp` headers and libraries

## Requirements

- `g++` or another C++17-compatible compiler
- `make`
- `pkg-config`
- `libopencv-dev`
- Mobilint MLA100 driver and runtime environment

## How to Build

Inside the extracted package directory:

```bash
make -j"$(nproc)"
cd build
./demo
```

The package `Makefile` builds the executable at `build/demo`.

## Runtime Configuration

The packaged application uses the files already included under `rc/`:

- `rc/LayoutSetting_MLA100.yaml`
- `rc/ModelSetting_MLA100.yaml`
- `rc/FeederSetting_MLA100.yaml`

When running `build/demo`, keep the package directory layout intact. The YAML files reference `../rc/...` and the model path references `../mxq/...` relative to the `build` directory.

## Feeder Setting

Edit `rc/FeederSetting_MLA100.yaml`.

Supported feeder types:

- `CAMERA`
- `IPCAMERA`
- `YOUTUBE`
- `VIDEO`

Example:

```yaml
- feeder_type: VIDEO
  src_path: ../rc/video/negative/8.mp4
```

`src_path` is a single string per feeder entry. To use multiple inputs, add multiple feeder entries.

## Model Setting

Edit `rc/ModelSetting_MLA100.yaml`.

Runtime-supported model types in the current package build:

- `YOLO11`
- `YOLO26`

Parser-accepted model type strings:

- `POSE`
- `FACENET`
- `STYLENET`
- `SEGMENTATION`
- `SSD`
- `YOLO11`
- `YOLO26`

Example:

```yaml
- model_type: YOLO26
  mxq_path: ../mxq/yolo26s-weapon_uint8_input.mxq
  dev_no: 0
  num_core: 8
```

Optional `core_id` entries are also parsed. If `num_core` is omitted, the code uses the number of `core_id` entries.

## Shortcuts

| Shortcut | Description |
| --- | --- |
| `D` / `d` | Toggle FPS overlay |
| `T` / `t` | Toggle running time overlay |
| `M` / `m` | Toggle fullscreen |
| `C` / `c` | Stop all workers |
| `F` / `f` | Start all workers |
| `Q` / `q` / `Esc` | Quit |
| `1`, `2`, `3` | Switch mode if extra config files are provided |

The extra mode-switch files are not part of the standard package contents.
